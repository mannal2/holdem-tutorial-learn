# 한 판씩 — 홀덤 첫걸음

React + Vite로 만든 홀덤 입문 학습 앱입니다. 정식 레슨01에서 승부 원리·5장 선택·원페어와 투페어, 레슨02에서 이기는 두 가지 방법과 팟 지급, 레슨03에서 딜러 버튼과 블라인드, 레슨04에서 개인카드 배분 순서, 레슨05에서 프리플랍 행동 순서, 레슨06에서 폴드·콜·레이즈, 레슨07에서 폴드 후 이미 낸 칩과 남은 칩, 레슨08에서 차액 콜과 BB의 체크, 레슨09에서 베팅 라운드의 종료 조건, 레슨10에서 플랍의 공용카드 공개, 레슨11에서 새로운 단계의 베팅 계산, 레슨12에서 플랍 이후 행동 순서, 레슨13에서 체크·베팅 이후의 대응을 배우고, 기존 첫걸음 체험에서 카드 배분·첫 행동자·추가 콜 금액을 연습합니다. 현재는 JavaScript/JSX이며 Motion·GSAP은 설치하지 않았습니다.

## 실행

Node.js 22.12 이상에서 실행합니다.

```sh
npm ci
npm run dev
```

브라우저에서 http://127.0.0.1:5188 을 엽니다.

## 검증과 빌드

```sh
npm run check
npx playwright install chromium
npm run test:e2e
```

`check`는 단위 테스트와 프로덕션 빌드를 실행합니다. 브라우저 테스트는 개발 서버를 켠 상태로 실행합니다. 빌드 결과는 `dist/`에 생성되며, 개발 서버를 종료한 뒤 `npm run preview`로 확인할 수 있습니다.

## Motion / GSAP 적용 지점

- 카드·플레이어는 React 컴포넌트이며 슬롯별 key를 유지합니다. 카드 등장·뒤집기·자리 강조는 `PlayingCard`와 `PlayerSeat`에 Motion을 적용할 수 있습니다.
- 배분 이동은 `playCardFlight({ card, source, target, reducedMotion, signal })`에 모았습니다. GSAP을 사용한다면 이 함수 안의 시각 효과를 교체하면 됩니다.
- 이동 함수는 애니메이션이 끝나면 Promise를 완료하고, `signal`이 취소되면 애니메이션을 중단해야 합니다. 시각 효과 안에서 칩이나 수업 단계를 직접 수정하지 않습니다.
- `useLesson`은 애니메이션 완료를 기다린 뒤 학습 상태를 갱신합니다. 이전·목차·다시 보기·컴포넌트 해제 시 진행 중인 재생을 취소합니다.
- `prefers-reduced-motion`에서는 카드 비행을 생략하되 동일한 수업 결과를 유지합니다.
- 라이브러리별 범용 엔진은 미리 만들지 않고, 실제로 필요한 시각 효과 단위로 교체합니다.

## 공통 베팅·체크 애니메이션

`playerAction(player, type, from, to)`로 행동을 만듭니다. 예를 들어 `playerAction(0, 'raise', 10, 30)`은 20칩을 이동하며, `playerAction(1, 'check', 10, 10)`은 칩 이동 없이 두 번 노크합니다. 이는 시각 효과용 데이터이며 전체 포커의 합법 행동 판정 엔진은 아닙니다.

`playPlayerAction`에는 행동, 출발점, 베팅 위치, `ActionEffect` 요소, AbortSignal과 모션 감소 설정을 전달합니다. 플레이어 강조 → 칩 이동 또는 노크 → 호출 측에서 금액 확정 → 잠시 결과 표시 순서입니다. 금액은 애니메이션 내부에서 변경하지 않습니다. 새 레슨에서도 같은 컴포넌트와 함수를 사용하고 각 레슨의 상태 갱신만 연결합니다.

헤더·목차·하단 문구·테이블 하단 중복 안내는 제거했습니다. 수업은 이전·다음으로 이동하며, 행동 중에는 해당 플레이어 위에 콜 금액 또는 체크가 표시됩니다.

상태는 레슨의 초기 테이블과 완료된 사건 목록에서 계산하므로 이전·다시 보기에서도 칩이 누적되지 않습니다. 배분 중 화면 크기를 바꾸면 현재 장면의 시작 상태로 복구하여 다시 재생할 수 있습니다. 새로고침하면 마지막 확정 단계로 돌아옵니다. 재생 중이라면 그 장면의 시작 상태로 복원하며 자동 재생하지 않습니다. 실제 홀덤 엔진과 상세 족보 수업은 아직 없습니다.

색상 토큰과 카드 뒷면 무늬는 사용자 소유의 `../holdem/frontend/src/styles/tokens.css`, `../holdem/frontend/src/components/cards/playing-card.css`를 참고했습니다. 실행·테스트는 해당 폴더에 의존하지 않습니다.

## 레슨 선택과 진도 저장

설명 패널 상단의 수업 표시를 누르면 목록을 엽니다. 첫걸음 체험은 이름으로, 정식 레슨은 현재 선택된 레슨 번호로 표시합니다. 현재는 첫걸음 체험과 레슨01·02·03·04·05·06·07·08·09·10·11·12·13을 선택할 수 있고, 레슨14~25는 준비 중으로 표시합니다. 수업 선택은 처음부터 다시 열며, 새로고침은 마지막 확정 위치를 복원합니다. 필수 질문과 관찰을 끝내면 완료 표시를 저장하고 이전/다시 보기에서도 유지합니다. 목록의 진도 초기화는 확인 후 이 앱의 진도만 지웁니다.

진도는 이 사이트 주소의 localStorage에 저장하며 다른 브라우저·기기와 공유하지 않습니다. 저장이 차단돼도 현재 학습은 계속할 수 있습니다. 데이터 키/형식과 검증은 [F1 구현 기록](docs/superpowers/plans/2026-10-12-f1-implementation.md)을 참조하세요.
