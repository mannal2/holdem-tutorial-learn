# 레슨 03 구현 기록 — 2026-10-13

대상: 03. 딜러 버튼과 블라인드.04~25는 구현하지 않는다. 기존 승인된 프로젝트와 실행 중인 서버에서 작업한다.

## 범위와 판단

- Ruling: 계획의5학습장면을11실행단계로 분리했다. 세 자리 선택 뒤 각각 결과를 확인하고 직접 다음을 누르는 기존 학습 문법을 유지한다. 비용: 결과 단계 수가 늘지만 새 개념은 추가하지 않는다.
- 질문은 설명창의 별도6개 선택 버튼 대신 테이블 자리 버튼으로 직접 답한다. 색뿐 아니라 BTN/SB/BB 문자, 관계 설명과 시계 방향 화살표를 제공한다. SB/P0, BB/P1, BTN/P5는 이번 판의 역할로 설명한다.
- BTN은 순서를 정하는 기준점으로 설명하고 실제로 카드를 직접 돌린다고 단정하지 않는다. 기존 덱 위치를 유지했다.
- 사용자가 계속 작업해 온 현재 holdem-tutorial 폴더의 main 체크아웃을 유지한다. 이번 요청은 레슨 구현이므로 커밋·푸시는 수행하지 않는다.
- Ruling:04가 미구현이므로03 완료는 주 버튼으로 재연습한다.04가 등록되면 공통 목록 기반 로직으로 다음 수업/보조 재연습으로 전환된다. 비용: 지금은04 이동이 제공되지 않는다.

## 구현 계약

- mainStart: 공통 본판 시작. BTN5/SB0/BB1, 스택 모두100, 기여0, 카드0, currentBet0. SB5/BB10의 post-blind 사건과 start0/blinds2 checkpoint를 정의했다. 원본 초기 카드/자리 자료는 기존 체험과 공유하므로 체험 제거 전에 공통 데이터로 옮기는 기존 후속 과제는 유지한다.
- post-blind: 상태의 역할 ID·SB/BB 금액을 검증한다. 카드 전 SB→BB 순서만 허용하고 중복/잘못된 역할·금액을 거절한다. 스택/스트리트 기여/핸드 기여를 한 번 갱신하며 프리플랍 행동 대기 순서는 소비하지 않는다. 부족한 스택/올인 블라인드 예외는 아직 이 레슨의 지원 범위가 아니다.
- playerAction의 blind 시각 데이터와 기존 공통 칩450ms 효과를 사용한다. 단계/컴포넌트별 재생 시간을 추가하지 않았다. 이동 완료 후 상태를 확정하고 취소 시 checkpoint로 복원한다.
- 목록에03을 등록했다.02 완료의 큰 버튼이03으로 자동 연결되고02 재연습은 아래 보조 버튼으로 바뀐다. 진도/완료 저장을 유지한다.
- 기존 미구현 수업 테스트의 대상만03에서04로 변경했다. 이전02 브라우저의 완료 후 재연습 진입만 보조 버튼으로 변경했다. 핵심 칩/완료/복원 검사는 유지한다.
- 명세5절의 남아 있던 예전300/350/650ms 설명을 이미 확정된 공통360/450/760ms 기준으로 맞췄다. 코드의 애니메이션 속도나 디자인은 변경하지 않았다.
