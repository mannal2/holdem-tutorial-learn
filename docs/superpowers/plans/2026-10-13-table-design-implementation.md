# 공통 테이블 문구·라벨 배치 수정 — 2026-10-13

사용자 승인: 모든 테이블의 펠트 워터마크와 상시 공용카드 안내를 제거하고, 작은 화면에서 결과 라벨과 개인카드가 겹치지 않도록 조정한다. 다음 레슨에도 같은 디자인을 적용한다.

- Table에서 felt-watermark와 board-caption 요소를 제거했다. 첫걸음 체험/01의 hand-preview/02의 outcome-preview를 포함해 공통으로 적용한다. 보드의 접근성 설명은 유지한다.
- seat-label을 hole-cards 내부로 옮겼다. 카드 영역 높이를 고정값에서 실제 카드 높이에 맞춰 늘어나는 구조로 변경하고 기존 최소 높이는 유지했다. 라벨 아래쪽을 카드 영역 위쪽에서6px 떨어뜨린다.
- 모바일에서 내 카드39px이 기존 카드 영역33px보다 커 위로 넘치던 구조를 해소했다. 내 카드·강조 크기와 라벨 글자 크기는 줄이지 않았다. 중앙 보드와 라벨 간격도 검사했다.
- 워터마크/보드 안내의 전용 CSS만 제거했다. 기존 테마·펠트·좌석 배치·설명 패널과 애니메이션은 유지했다.
- 전체 구현계획과 디자인 명세에 ‘공통 테이블의 문구와 카드 위 라벨’ 기준을 추가했다. 신규 레슨에서도 상시 문구를 복원하지 않으며, 공용카드 개념은 필요한 파트의 설명창에서 안내한다.
- 변경 전 브라우저 검사에서 제거 대상 요소2개가 남아 실패하는 것을 확인했다. 변경 후1366/475/390/320px에서 모든 테이블 모드의 문구 제거와01/02 승리 라벨의 카드·보드 간격 검사가 통과했다.475px의02 화면 캡처를 직접 확인했다.
